# 🌐 BookEase Frontend

This is the **frontend** part of the BookEase project — a book management and reading list web app. It interacts with the Django REST API backend to provide user-friendly features for managing books, user profiles, and personal reading lists.

---

## 🔗 Live Demo

👉 [BookEase Frontend Live](https://bookease-9x57.onrender.com)

---

## 🧰 Tech Stack

- **React.js**
- **Axios**
- **Tailwind CSS** (or other styling library you used)
- **React Router**
- **JWT Authentication** for secure API access

---

## 📦 Project Setup

### 1. Clone the Repo

      git clone https://github.com/your-username/bookease-frontend.git
      
      cd bookease-frontend

2. Install Dependencies

       npm install

4. Run the Project Locally

       npm run dev

🔐 Authentication Flow
JWT tokens (access & refresh) are securely stored

Axios interceptors handle token injection and refresh logic

Auth-protected routes are implemented using React Router

🧪 Features Overview
✅ Register / Login

✅ View & update profile

✅ View all books

✅ Add/remove books

✅ Create and organize reading lists
